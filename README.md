### What I do

I lead builds for startups: the spec, the architecture, the decisions and the review. Most of the code is now written by AI agents I direct, then checked by me and a small team. My studio, [IkeWebStudio](https://www.ikewebstudio.com), builds first-version web apps this way.

### Selected work

Most client work is under NDA, so clients stay unnamed.

- **Apps at scale:** several projects on apps with millions of users.
- **Government cybersecurity delivery:** took over an at-risk release and led it through stakeholder approval.
- **Fintech:** launched products for a startup and a large national bank, with PCI and SOC 2 requirements built into delivery.
- **Series A marketplace:** led a team of six. Retention up 17%, API latency down 30%, 10+ hours a week saved in support operations.
- **Data:** a sentiment-analysis pipeline processing over 1 million tweets a day for financial price modeling.
- **AI engineering:** internal AI tooling with guardrails for an enterprise client, balancing agent autonomy with human review.
- **Startup V1:** under a tight deadline, my studio built the [Vamo Fellowship](https://www.vamofellowship.com) V1 app, with user dashboard, admin panel and team workspaces.
